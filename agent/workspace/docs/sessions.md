# Сессии и статистика уборки

## Сессия

Каждый запуск уборки формирует сессию (`Session`):

- `id`, `robotId` — идентификаторы сессии и робота;
- `startedAt`, `endedAt` — время начала и конца (ISO-8601);
- `durationMinutes` — длительность в минутах;
- `areaCleaned` — убранная площадь;
- `mode` — режим уборки (`dry_sweep` или `wet_mopping`);
- `aborted` — флаг прерванной уборки (сессии, завершённые командой
  `ABORT`, помечаются этим флагом).

## История

`GET /robots/{id}/sessions?from&to` возвращает историю сессий за период.
Параметры `from` и `to` — ISO-8601, оба опциональны: без них отдаётся вся
история. Сессии отсортированы по времени.

Симулятор хранит данные в памяти: при перезапуске расписания сбрасываются,
а история генерируется заново за последний месяц — примерно 40 сессий на
робота.

## Статистика

Экран статистики приложения агрегирует историю за выбранный период:
количество сессий, суммарная убранная площадь, средняя длительность,
доля прерванных (aborted) сессий. Отдельно считается статистика по
режимам уборки.
