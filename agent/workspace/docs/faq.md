# FAQ cleanbot-ops

**Какой приоритет у задач по умолчанию?**
Если пользователь не указал приоритет задачи, используется `mid` — средний.
Значения приоритета: `low`, `mid`, `high`. Срочные задачи помечаются `high`.

**Где взять адрес симулятора?**
В инженерном меню приложения: для Android-эмулятора это `ws://10.0.2.2:8080`
(10.0.2.2 — loopback хост-машины), для физического устройства —
`ws://<IP-компьютера-в-той-же-сети>:8080`.

**Что происходит с данными при перезапуске симулятора?**
Симулятор хранит данные в памяти: расписания и история сбрасываются,
история заново генерируется за последний месяц (~40 сессий на робота).

**Есть ли авторизация?**
Нет. Один пользователь, без авторизации и ролей — осознанное ограничение MVP.

**Запускает ли расписание уборку автоматически?**
Да. Раз в 15 секунд сервер сверяет день недели и время (локальная таймзона
сервера) с расписаниями; совпавшая запись стартует уборку (режим берётся из
записи), если робот в IDLE, иначе запись «пропущено» попадает в журнал.
