# Настройки робота и инженерное меню

## Настройки робота

Настройки робота (`RobotSettings`) хранятся отдельно от телеметрии:

- `robotId` — идентификатор робота (не меняется);
- `displayName` — отображаемое имя машины;
- `serverAddress` — адрес сервера, к которому робот подключается.

Чтение: `GET /robots/{id}/settings`. Обновление: `PUT /robots/{id}/settings`.
Если `robotId` в теле запроса не совпадает с идентификатором в пути,
ответ — 400 (нельзя переименовать одного робота, отправив настройки
другого).

## Инженерное меню

Инженерное меню в Android-приложении позволяет:

- переименовать робота (`displayName`);
- указать адрес симулятора (`serverAddress`) — для эмулятора
  `ws://10.0.2.2:8080`, для физического устройства IP компьютера в
  локальной сети;
- посмотреть журнал событий робота (новые записи сверху).

## Журнал событий

`GET /robots/{id}/logs` возвращает журнал (`LogEntry`): время, робот,
уровень (`INFO`, `WARN`, `ERROR`) и текст. В журнал попадают: старт и
окончание уборки, отклонённые команды, пропуски записей расписания,
ошибки робота.
