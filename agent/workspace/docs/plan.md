# План уборки: сетка, зоны, маршрут

## Сетка мира

План уборки живёт на фиксированной сетке `20 × 14` клеток
(`GRID_WIDTH=20`, `GRID_HEIGHT=14`). Координаты `position` из телеметрии
маппятся на клетки сетки один к одному.

## Зоны

Зона (`Zone`) — именованный набор клеток внутри сетки:

```json
{ "id": 1, "name": "Склад", "cells": [ { "x": 0, "y": 0 }, { "x": 1, "y": 0 } ] }
```

У каждой зоны должно быть хотя бы одна клетка; дублирующиеся клетки
(внутри зоны или между зонами) запрещены — валидация вернёт ошибку с
координатами. Клетки вне сетки 20×14 тоже отклоняются.

## Маршрут «змейкой»

Симулятор сам строит маршрут обхода (`route`) — порядок обхода клеток
«змейкой» — и отдаёт его в `GET /plan`. В `PUT /plan` поле `route`
игнорируется: его нельзя задать вручную.

Во время уборки робот проходит одну клетку маршрута за тик;
`progress` из телеметрии — доля пройденных клеток маршрута.

## Чтение и запись плана

- `GET /robots/{id}/plan` — текущий план с маршрутом;
- `PUT /robots/{id}/plan` — заменить план целиком; ошибка валидации
  (пустая зона, клетка вне сетки, дубль клетки) возвращает 400 с текстом.
