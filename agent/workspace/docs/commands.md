# Команды робота

Команда отправляется через `POST /robots/{id}/commands` с телом:

```json
{ "command": "START", "requestId": "q-42" }
```

## Допустимые команды

| Команда | Что делает | Из каких состояний принимается |
|---|---|---|
| `START` | запустить уборку | `IDLE` |
| `PAUSE` | поставить уборку на паузу | `CLEANING` |
| `RESUME` | продолжить уборку | `PAUSED` |
| `ABORT` | прервать текущую уборку | `CLEANING`, `PAUSED` |
| `RETURN_HOME` | отправить на базу | `IDLE`, `CLEANING`, `PAUSED` |
| `RESET` | сбросить состояние ошибки | `ERROR` |

Команда, недопустимая в текущем состоянии, отклоняется с кодом `ILLEGAL_STATE`.

## Ответ на команду

Симулятор отвечает `CommandResponse`: `accepted` (bool), `requestId`
(эхо из запроса) и `reason` (текст причины отказа, только при
`accepted=false`).

Пример отказа:

```json
{ "accepted": false, "requestId": "q-42", "reason": "ILLEGAL_STATE" }
```

## Прерывание и сброс ошибки

`ABORT` завершает текущую сессию уборки — в статистике такая сессия
помечается флагом `aborted=true`. После `ABORT` робот переходит в
`RETURNING` и затем в `CHARGING`.

`RESET` работает только из состояния `ERROR`: он возвращает робота в
`IDLE`. Из других состояний `RESET` отклоняется.
