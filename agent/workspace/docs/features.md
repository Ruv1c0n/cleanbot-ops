# Возможности cleanbot-ops

Android-консоль для парка промышленных клининговых роботов:
Kotlin, Jetpack Compose, MVVM + StateFlow, Ktor (WS-клиент).

| Модуль | Что умеет |
|---|---|
| Парк роботов | список машин: состояние, заряд, бейдж ошибок |
| Дашборд робота | состояние, заряд, прогресс уборки, конкретизация ошибок |
| Команды | запустить уборку, пауза, продолжить, прервать, вернуть домой |
| Расписания | просмотр и редактирование расписания уборок |
| Сессии и статистика | история уборок за период, агрегированная статистика |
| Инженерное меню | настройки робота (имя, адрес сервера), журнал событий |

Каждый робот в симуляторе — детерминированная машина состояний (FSM):
IDLE -> CLEANING -> PAUSED -> RETURNING -> CHARGING, плюс ERROR с выходом
командой RESET. Команда, недопустимая в текущем состоянии, отклоняется с
кодом ILLEGAL_STATE.
